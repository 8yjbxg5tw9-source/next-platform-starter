kompüterdə "Bu abunəlik başqa cihazda aktivdir!" mesajı görəcək.

Müddət hazırda limitsizdir. Müştəriyə müddət qoymaq / uzatmaq üçün:
  python tools/add_user.py --username akai01 --renew 30      # 30 gün
  python tools/add_user.py --username akai01 --renew 365     # 1 il
  python tools/add_user.py --username akai01 --renew 0       # limitsiz
(--renew yalnız bitmə tarixini dəyişir; şifrə və bağlı HWID toxunulmaz qalır.)

Yeni hesab lazım olsa:
  python tools/add_user.py --username yeni_ad --password yeni_kod --days 0
